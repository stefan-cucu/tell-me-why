# Chapter 4: Explainability

Runs category ablation, Kernel SHAP, Integrated Gradients, entry aggregation, and the related plots.

## Files

- `run_explainability.py`: Runs the requested explainability stages and writes their numerical results.
- `plot_explainability.py`: Creates the Chapter 4 figures from the saved results.
- `run_all.sh`: Runs all explainability stages and then creates the figures.
